# SENTINEL — Crime Detection AI Dashboard

Real-time crime detection application built with Python, Dash, OpenCV, and Ultralytics YOLO models.

## Features
- Upload support for video and image files
- Real-time detection of suspicious objects and violent activity
- Weapon detection (pistol/rifle)
- Fight/violence detection
- Motion-based alert logic
- Interactive Dash dashboard with alert summaries and charts

> **Note:** Live webcam mode is not available in this cloud deployment. Use the video/image upload feature instead.
